In other words, private non-commercial modifications are not the same as permission to publish a modified fork, patch, derivative app or modified build.

A GitHub fork should not be read as blanket permission to publish or distribute modified versions outside the permissions granted by the applicable licence. See:

## Contributions

Because the default licence does not permit sharing adapted material, the project does not accept unsolicited code or documentation pull requests. Open an issue or contact the maintainers first. A contribution may be submitted for inclusion only after the maintainer has given written approval and the contributor has agreed separately to the permissions needed for the proposed contribution and its distribution.

See [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Important note about software licensing

Creative Commons advises against using CC licences for software. CC licences were designed for creative works rather than software and do not contain software-specific source-code or patent terms; CC notes that this can make reuse and compatibility with software projects difficult. FlightSaver's use of CC BY-NC-ND is the maintainer's chosen restriction, but it should not be described as an OSI-approved open-source licence. See the [Creative Commons FAQ](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software) and the [Open Source Definition](https://opensource.org/osd).
