# Security policy

## Supported versions

Security fixes are developed for the latest version on the default branch and the latest published release. Older releases may not receive fixes. Please update to the latest version before reporting an issue where possible.

## Reporting a vulnerability

Please do **not** open a public issue containing exploit details, credentials, API keys, private location data, personal paths or a weaponisable proof of concept.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/Isaaker/FlightSaver/security/advisories/new>

If private reporting is unavailable, open a minimal issue asking for a private contact channel without disclosing the vulnerability details.

Include the affected version or commit, macOS version, Mac architecture, impact, and concise reproduction steps. Redact API keys, account identifiers, home-directory paths and any location you do not wish to disclose.

## Scope

FlightSaver is a community screen saver and is not safety-critical software. Nevertheless, vulnerabilities affecting local data, stored provider keys, network requests, update artifacts or bundled code are welcome to report.

Please allow the maintainer reasonable time to investigate and prepare a fix before public disclosure.
